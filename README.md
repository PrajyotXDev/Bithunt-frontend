## About Bithunt

**Bithunt** is a coding competition focused on practical problem-solving and algorithmic thinking. Participants will navigate **two rounds** over a **3-hour** competition, using the programming language of their choice on a custom-built competition platform.

The frontend is designed around a **dark, technical, terminal-inspired visual language** — combining sharp layouts, monospace interface elements, scanline textures, neon accents, and interactive competition-focused sections.

> This project takes visual inspiration from cyberpunk/terminal interfaces while using an original Bithunt layout and implementation.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/PrajyotXDev/Bithunt-frontend.git
cd Bithunt-frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

### 4. Open the app

Visit:

```text
http://localhost:3000
```

## Design Principles

The Bithunt interface follows a few core principles:

**01 — Technical**  
The interface should immediately feel connected to programming and competitive coding.

**02 — Focused**  
Visual effects support the content rather than overpowering it.

**03 — Competitive**  
Rankings, rounds, timers, status indicators, and progress should feel like part of an active challenge.

**04 — Responsive**  
The experience should work cleanly from desktop monitors to mobile screens.

**05 — Original**  
References can influence the visual language, but Bithunt's identity and implementation remain its own.
